# 数据字典

| 字段名 | 类型 | 单位或取值范围 | 含义 |
|---|---|---|---|
| `date` | 日期 | YYYY-MM-DD | 当天记录日期 |
| `sleep_duration_hours` | 数字 | 0–14 小时 | 前一晚实际睡眠时长 |
| `sleep_quality` | 整数 | 1–5 | 醒来后的主观恢复感评分 |
| `study_minutes` | 整数 | 小时 | 当天总学习时长 |
| `deep_focus_minutes` | 整数 | 小时 | 高质量、低分心学习时长 |
| `phone_entertainment_minutes` | 整数 | 小时 | 非学习用途的手机使用时间 |
| `exercise_minutes` | 整数 | 小时 | 当天主动运动时长 |
| `class_load` | 分类变量 | 低 / 中 / 高 | 当天课程与任务负担 |
| `focus_score` | 整数 | 1–5 | 当天总体学习专注评分 |
| `notes` | 文本 | 影响当天状态的重要事件 |
